# LLM wiki

The owner's knowledge base, kept by their agents and browsed by the owner in Obsidian. Read this page first, then follow
links.

## How it works

- One topic per page. File names are lowercase-kebab (`frontend-layering.md`), and pages link to each other with
  `[[frontend-layering]]`. Links are what build the graph, so link generously.
- Every page starts with frontmatter: `type` (person, decision, topic) and `updated` (date).
- Facts that last go here. Working state (what's on hold today) stays in each agent's `memory/` notes.

- [[frontend-layering]]: a pattern for keeping frontend codebases from turning into slop.
