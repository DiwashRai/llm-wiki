# LLM wiki

The owner's knowledge base, kept by their agents and browsed by the owner in Obsidian. Read this page first, then follow
links.

## How it works

- Pages apply only when a workflow points to them or the owner asks.
- One topic per page. File names are lowercase-kebab (`frontend-layering.md`), and pages link to each other with
  `[[frontend-layering]]`. Links are what build the graph, so link generously.
- Every page starts with frontmatter: `type` (person, decision, topic) and `updated` (date).
- Facts that last go here. Working state (what's on hold today) stays in each agent's `memory/` notes.

## Topics

- [[weekly-review]]: how to run the owner's twice-weekly reviews.

## Writing styles

A style covers the prose asked for, not code, commands or quotes.

- [[bluf-writing-style]]: conclusion first. Combines with other styles.
- [[runbook-writing-style]]: pages that tell an agent what to do.
- [[ste-writing-style]]: Simplified Technical English, for strict procedures and specs.
- [[telegraphic-writing-style]]: periodic reviews and status notes.
