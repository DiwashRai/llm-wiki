# BLUF

Bottom line up front. Use for answers, recommendations and reports. Can be combined with another style.

Meaning comes first. If a rule would obscure it, adapt the rule.

- Open with the conclusion or recommendation, and how sure it is, if not certain. If there isn't one yet, say so.
- State any action needed from the reader up top.
- Follow with the support the reader needs, including any risk that could change the decision.

## Example

**Probably remove the cache layer.** It added no measurable speed in testing, but production load is untested.
