# Telegraphic style

Use for periodic reviews and status notes. Not for procedures or long reasoning.

Meaning comes first. If a rule would obscure it, adapt the rule.

- Use fragments. Drop articles and filler.
- Keep words that change meaning, such as not, only, if, unless, until, because and hedges.
- Put one item in each bullet, label first.
- Say if something is planned or unverified, when not obvious.
- Put extra context in a sub-bullet.
- Cut words, not facts or caveats.
- Each bullet must make sense without this thread.

## Example

- Login page: works locally, not deployed.
- Billing export: planned, due Friday.
  - Blocked unless API key arrives.
