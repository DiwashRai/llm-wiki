# Software factory design

See also [[quality-gates]].

## Brakes

Brakes are parts of the Factory system that:

- guide the agent to code within your constraints from the start
- limit the scope and type of mistakes it can make while working
- verify its work before commit using multiple layers of checks and reviews
- raise outputs to your attention when needed, according to criteria you choose
