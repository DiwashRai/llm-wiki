# Simplified Technical English

Use for procedures and specs that need strict, unambiguous wording.

Meaning comes first. If a rule would obscure it, adapt the rule.

- Without a copy of ASD-STE100, approximate it: active voice, one instruction per sentence, one term
  per meaning. Don't claim conformance.
- Reference: https://www.asd-ste100.org/
